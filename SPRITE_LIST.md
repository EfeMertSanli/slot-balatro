## TIPS FOR GEMINI IMAGE GENERATION

1. **Always specify "PC-98 style pixel art"** - This sets the aesthetic
2. **Include "16-color palette"** - Enforces the limited color restriction
3. **Mention "Japanese retro computer game"** - Helps with the specific style
4. **Specify exact dimensions** - Important for game integration
5. **Request "transparent background"** - For sprites that need alpha
6. **Add "clean pixel edges"** - Avoids anti-aliasing that breaks the aesthetic

If Gemini struggles with pure pixel art, you can:
- Generate at higher resolution and manually pixel-ify
- Use the outputs as references for manual pixel art
- Request "in the style of Touhou Project or YU-NO" for better PC-98 references
